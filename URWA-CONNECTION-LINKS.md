## Supabase Auth URL values

Set the **Site URL** to:

```text
https://gleaming-queijadas-521c0f.netlify.app
```

Add these **Additional Redirect URLs**:

```text
https://gleaming-queijadas-521c0f.netlify.app/**
http://localhost:5500/**
```

The localhost entry is only for local testing with VS Code Live Server on port 5500. Save these values in Supabase Auth URL Configuration. The site's confirmation and password-recovery code uses explicit redirects on the Netlify origin.
